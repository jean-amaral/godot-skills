# Changelog — godot-multiplayer-2d

- Skill inicial sobre o núcleo `godot-multiplayer`: sincronização 2D com autoridade (avatar de plataforma/top-down interpolado, estado de movimento como dado), o conflito interpolação × snap de pixel com decisão registrada, estado alterável de TileMap com registro para quem entra tarde, inimigos simples na autoridade e os três desenhos de câmera co-op (independente, grupo/tether, split-screen).
