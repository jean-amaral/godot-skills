# Changelog — godot-2d-specialist

## 1.0.0 — 2026-10-17

- Skill inicial, par 2D da `godot-3d-specialist` (Godot 4.7+): movimento de plataforma/top-down com ficha numérica em tiles (coyote, buffer, pulo variável, dash), TileMapLayer/TileSet com terrenos e dados customizados, física 2D (camadas, hitbox/hurtbox, projéteis), estrutura/estados/navegação 2D reaproveitando os componentes do pacote, sob o protocolo de pesquisa comum. O 2D sai do "fora de escopo" registrado da skill 3D e ganha casa própria.
