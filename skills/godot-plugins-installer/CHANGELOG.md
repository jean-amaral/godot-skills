# Changelog — godot-plugins-installer

## 1.0.0 — 2026-10-17

- Skill inicial: instalação dos três plugins do fluxo do criador (Phantom Camera v0.11.0.3, CSG Blockout v3.1.0, Godot AI v4.3.0) somente das fontes oficiais, com matriz de compatibilidade por engine (4.4+/4.6+/4.7+), confirmação antes de sobrescrever, script PowerShell das releases oficiais (asset v4 correto do Godot AI, não a ponte de migração), provas de instalação por plugin e o passo de ligar o cliente MCP pelo dock do Godot AI. Versões e APIs conferidas nos repositórios oficiais nesta data.
